Social Media Bell

    Sites

    X and Reddit are checked in the background; no tab needed. The others are read from the unread count in their tab title, so keep a tab open for each (pinning it works well).

    Options

    Settings

    Social Media Bell uses this browser's existing sign-ins. For X and Reddit it asks for the same unread count their websites show; for the other sites it only reads the open tab's title. Nothing is sent anywhere else.

    No alerts showing up? Allow notifications for your browser in System Settings → Notifications, and check Focus modes.
